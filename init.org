** What is Kickstart.emacs?
Kickstart.emacs is *not* a distribution.
It's a template for your own configuration.
Inspired by kickstart.nvim.

It is *recommended* to configure it from the *init.org* file.

Kickstart.emacs is a starting point for your own configuration.
The goal is that you read every line, top-to-bottom, understand
what your configuration is doing, and modify it to suit your needs.

After you've done that, you can start making your own configuration out of this
or taking the things you like and making something new from scratch.
The choice is yours. You can do basically anything with Emacs.
So don't hesitate to try things out.

You can delete this when you're done. It's your config now. :)
I hope you have fun with your Emacs journey.
MiniApollo

** Ctrl & Meta
This is from the Emacs tutorial, but I put this here for safety.

Emacs commands generally involve the CONTROL key (often labeled CTRL)
or the META key (usually labeled ALT). Rather than writing that
in full each time, we'll use the following abbreviations:

C-<chr>  means hold the CONTROL key while typing the character <chr>.
Thus, C-f would be: hold the CONTROL key and type f.
M-<chr>  means hold the META or ALT key down while typing <chr>.
If there is no META or ALT key, instead press and release the
ESC key and then type <chr>.  We write <ESC> for the ESC key.

** Where to start?
First I recommend starting with the Emacs tutorial with the following keybinding: C-h t
Or running the command with M-x: help-with-tutorial
Even if you plan on using Vim keybindings later on, it's a good idea to learn the standard Emacs keybindings.
If you already know the standard Emacs keybindings, you can skip this step.

After you complete that, you should start learning Emacs lisp.
It is not necessary to know elisp, but I recommend it. It will open up a whole new world, trust me.
I used Emacs and Neovim without knowing much about the core language and just copy-pasting packages or plugins.
But after learning the fundamentals you can customize basically anything and I really mean ANYTHING.

This will look daunting at first, but don't be scared. This is why I am here.
Elisp is not harder than lua or any other language.

If you don't know anything about elisp, I recommend taking some time to read through
a guide. One possible example which will only take 10-15 minutes:
https://learnxinyminutes.com/elisp/

Or if you want to know everything about elisp:
https://www.gnu.org/software/emacs/manual/html_node/eintr/

** Getting Help
If you get stuck or confused about something, you're in luck:
Because Emacs has a really good help functionality.
Everything under C-h is used for help keybindings.

Using the following keybind: C-h C-h
Or running the following command M-x: help-for-help
Will open up the Emacs help for help menu (I know it's a really creative name :D).
This is the central place where you can see all possible commands you can use when you are stuck.

The most used commands for me are:
- C-h v Describe variable
- C-h f Describe function
- C-h k Describe key

Other also really useful ones:
- C-h i Show all installed manuals
- C-h r Emacs manual
- C-h a Search for commands (see also M-x: Apropos)
- C-h m Show help for current major and minor modes

These commands should be the first thing you use when you're stuck or confused with something.

*** Searching the manual
The manual has a specific mode called info-mode.
Which has useful features you can use.
For more about info-mode: C-h f: info-mode

Basic navigation:
- d key: Go back to the top-level Info Directory.
- u key: Go up to the parent node in the document's hierarchy.
- n key: for next node in the current manual.
- p key: for previous node in the current manual.

*Note:* A Node is essentially a specific section or topic, much like a chapter or subsection in a book.

When you are browsing through the Emacs manual you can easily search with:
- i key: for specific subjects in the current manual.
- g key: for nodes (sections).
- m key: for menu items within the current Info buffer.
- s key: for regular expression patterns (like words) within the current Info buffer.

For evil users after setting up evil collection for info mode:
- g-j: for next node in the current manual.
- g-k: for previous node in the current manual.
- g-G: for nodes (sections).
- g-m: for menu items within the current Info buffer.
- The other keybinds are the same
To see all the evil [[https://github.com/emacs-evil/evil-collection/blob/master/modes/info/evil-collection-info.el][keybindings]] for info mode.

Using goto-node:
- Specify a Manual: If you want to search within a particular manual, place its name in parentheses like (emacs).
- After that tell where you want to go in that manual. For example (emacs)Top, (emacs)specific section.
- If you don't type a manual name, goto-node will search the currently opened manual.

** Auto-tangle Configuration file
Auto-Tangle Org configuration file for better startup times, it refreshes the package-quickstart file.
We'll cover package quickstart in the package manager section later.

If you like to auto tangle an Org file, don't forget to add the following line to the top of your Org document:
(#+PROPERTY: header-args:emacs-lisp :tangle ./init.el :mkdirp yes)

*Remember*, if this code can't be loaded (errors before this code), the init.el file won't update on change!
To fix this, you need to find this file (C-x C-f), fix the error and press C-c C-v t to tangle it manually.

This snippet adds a hook to org-mode buffers so that start/org-babel-tangle-config gets executed each time such a buffer gets saved.
This function checks to see if the file being saved is the init.org file you’re looking at right now, and if so,
automatically exports the configuration here to the associated output files.
#+begin_src emacs-lisp
    (defun start/org-babel-tangle-config ()
      "Tangle only init.org, then refresh `package-quickstart'."
      (interactive)
      (when (and (buffer-file-name)
                 (string-equal (file-name-nondirectory (buffer-file-name)) "init.org")
                 (string-equal (file-name-directory (buffer-file-name))
                               (expand-file-name user-emacs-directory)))
        (let ((org-confirm-babel-evaluate nil))
          (org-babel-tangle))))

    (add-hook 'org-mode-hook (lambda () (add-hook 'after-save-hook #'start/org-babel-tangle-config)))
#+end_src

** Network reliability
EWW and package.el retrieve URLs through the same layers: =url-retrieve= -> GnuTLS -> TCP,
and url.el's DNS lookups are synchronous.  When one layer stalls, EWW hangs on
"Loading <url>..." forever and =package-refresh-contents= hangs on "Contacting host:
melpa.org" — one root cause, two symptoms.  C-g always recovers because Emacs is
waiting inside a process filter (interruptible), not inside a blocking syscall.

Emacs itself has no timeout for plain =url-retrieve=: if DNS or the TLS handshake
stalls, the request never finishes, which is why "Loading ..." can stay on screen
for hours.  The pieces below make every layer either bounded or external (curl
races IPv4/IPv6 and enforces its own deadlines in a subprocess), and give you a
diagnosis tool that cannot hang.

Usual suspects, in order of likelihood:
1. *Stale proxy settings* left in the environment by a VPN/proxy client.
   Check =M-: (list (getenv "https_proxy") (getenv "http_proxy"))= and
   =C-h v url-proxy-services=.  If Emacs should not use a proxy at all:
   =(setq url-proxy-services nil)=.
2. *Broken IPv6*: Emacs dials the AAAA address first and waits out the OS timeout.
   Compare in a shell: =curl -4 https://news.ycombinator.com= vs =curl -6 ...=;
   if only -6 hangs, the IPv6 route is black-holed (fix on the OS/router side).
3. *Stalled TLS handshake*: black-holed MTU on PPPoE/VPN links, or the historical
   GnuTLS 3.6 TLS 1.3 hang (Emacs bug#34293).
4. *A hidden NSM prompt*: the Network Security Manager can be waiting on a
   minibuffer question about a certificate — check the minibuffer/echo area.

When something hangs, run =M-x my/net-doctor=: six curl subprocess probes (forced
IPv4/IPv6, MELPA, GNU ELPA, NonGNU ELPA, DuckDuckGo) plus one asynchronous url.el
probe, each with its own deadline, so the doctor can never freeze Emacs.
#+begin_src emacs-lisp
    ;; Debugging aids — leave commented out until needed:
    ;; (setq url-debug t)          ; log every url.el step to *URL-DEBUG*
    ;; (setq gnutls-log-level 2)   ; log the TLS handshake to *Messages*
    (require 'subr-x) ; string-trim, used by the doctor below
    ;; EWW fetches page images through a work queue; make stuck image
    ;; fetches give up instead of piling up on a flaky connection.
    (setq url-queue-timeout 10)
    ;; Fix for permanent "Contacting host" hangs with GnuTLS 3.6.x
    ;; (Emacs bug#34293): stop offering TLS 1.3.  Only enable this if
    ;; my/net-doctor shows TLS connections timing out while curl succeeds.
    ;; (setq gnutls-algorithm-priority "NORMAL:-VERS-TLS1.3")
    ;; Don't let a manual M-x package-refresh-contents hang forever either:
    ;; give the archive download two minutes, then report.
    (define-advice package-refresh-contents
        (:around (orig-fn &rest args) my/refresh-timeout)
      "Give up after two minutes instead of hanging on a stalled network."
      (condition-case err
          (with-timeout (120) (apply orig-fn args))
        ((error timeout)
         (message "package-refresh-contents aborted: %s; network looks broken, try M-x my/net-doctor"
                  (error-message-string err))
         nil)))

    ;; ---------------------------------------------------------------------------
    ;; my/net-doctor v3 — external-process probes; can never freeze Emacs.
    ;; ---------------------------------------------------------------------------
    (defvar my/net-doctor-probe-timeout 15
      "Seconds after which curl gives up on a single probe.")

    (defvar my/net-doctor-url-probe-timeout 15
      "Seconds after which the Emacs url.el probe is killed.")

    (defvar my/net-doctor--curl-exit-messages
      '((1 . "unsupported protocol")
        (2 . "bad curl command line (often an empty/blank URL argument)")
        (3 . "malformed URL (raw space/newline/control char, or [range] without -g)")
        (5 . "couldn't resolve PROXY (stale proxy env?)")
        (6 . "couldn't resolve host - DNS broken")
        (7 . "couldn't connect - TCP refused/unreachable")
        (22 . "HTTP 4xx/5xx response")
        (28 . "timeout - connection stalled (often TLS/MTU blackhole)")
        (35 . "TLS handshake error")
        (47 . "too many redirects (often a cookie-hungry site)")
        (52 . "empty reply from server")
        (60 . "TLS certificate verification failed"))
      "Human-readable meanings of the curl exit codes the doctor can hit.")

    (defvar my/net-doctor-curl-probes
      (list
       (list "IPv4  news.ycombinator.com"
             (list "-4" "-sS" "-o" "/dev/null" ; Windows: replace with nul
                   "--connect-timeout" "8"
                   "-m" (number-to-string my/net-doctor-probe-timeout)
                   "-w" "remote_ip=%{remote_ip} http=%{http_code} total=%{time_total}s"
                   "https://news.ycombinator.com"))
       (list "IPv6  news.ycombinator.com"
             (list "-6" "-sS" "-o" "/dev/null"
                   "--connect-timeout" "8"
                   "-m" (number-to-string my/net-doctor-probe-timeout)
                   "-w" "remote_ip=%{remote_ip} http=%{http_code} total=%{time_total}s"
                   "https://news.ycombinator.com"))
       (list "MELPA melpa.org"
             (list "-sS" "-o" "/dev/null"
                   "--connect-timeout" "8"
                   "-m" (number-to-string my/net-doctor-probe-timeout)
                   "-w" "remote_ip=%{remote_ip} http=%{http_code} total=%{time_total}s"
                   "https://melpa.org/packages/"))
       (list "GNU ELPA elpa.gnu.org"
             (list "-sS" "-o" "/dev/null"
                   "--connect-timeout" "8"
                   "-m" (number-to-string my/net-doctor-probe-timeout)
                   "-w" "remote_ip=%{remote_ip} http=%{http_code} total=%{time_total}s"
                   "https://elpa.gnu.org/packages/"))
       (list "nongnu elpa.nongnu.org"
             (list "-sS" "-o" "/dev/null"
                   "--connect-timeout" "8"
                   "-m" (number-to-string my/net-doctor-probe-timeout)
                   "-w" "remote_ip=%{remote_ip} http=%{http_code} total=%{time_total}s"
                   "https://elpa.nongnu.org/nongnu/"))
       ;; Probing the exact endpoint EWW searches on (Emacs 31 default
       ;; `eww-search-prefix').  http=202 means DDG served its anti-bot
       ;; challenge to this client — site-side judgement about UA/IP
       ;; reputation, NOT a network failure.
       (list "DuckDuckGo html endpoint"
             (list "-sS" "-o" "/dev/null"
                   "--connect-timeout" "8"
                   "-m" (number-to-string my/net-doctor-probe-timeout)
                   "-w" "remote_ip=%{remote_ip} http=%{http_code} total=%{time_total}s"
                   "https://html.duckduckgo.com/html/?q=emacs")))
      "curl probes run by `my/net-doctor'; each entry is (LABEL (curl ARGS...)).")

    (defun my/net-doctor--curl-exit (code)
      "Describe curl exit code CODE using `my/net-doctor--curl-exit-messages'."
      (cond
       ((< code 0) (format "killed by signal %s" (- code)))
       (t (or (cdr (assq code my/net-doctor--curl-exit-messages))
              (format "exit %s" code)))))

    (defun my/net-doctor--report (buffer label status &optional detail)
      "Append one report line for LABEL and STATUS to BUFFER."
      (when (buffer-live-p buffer)
        (with-current-buffer buffer
          (let ((inhibit-read-only t))
            (goto-char (point-max))
            (insert (format "%-30s %-44s %s\n" label status (or detail "")))
            (let ((win (get-buffer-window buffer t)))
              (when win (set-window-point win (point-max))))))))

    (defun my/net-doctor--run-curl (report-buffer label args)
      "Run one curl probe with ARGS; report to REPORT-BUFFER when it finishes."
      (condition-case err
          (let ((pbuf (generate-new-buffer " *net-doctor probe*"))
                (errbuf (generate-new-buffer " *net-doctor stderr*")))
            (make-process
             :name (concat "net-doctor-"
                           (replace-regexp-in-string "[^A-Za-z0-9]+" "-" label))
             :buffer pbuf
             :stderr errbuf
             :command (append (list "curl") args)
             :sentinel
             (lambda (proc _event)
               (unless (process-live-p proc)
                 (let* ((out (and (buffer-live-p pbuf)
                                  (with-current-buffer pbuf (buffer-string))))
                        (errs (and (buffer-live-p errbuf)
                                   (string-trim
                                    (with-current-buffer errbuf (buffer-string)))))
                        (code (process-exit-status proc)))
                   (when (buffer-live-p pbuf)
                     (kill-buffer pbuf))
                   (when (buffer-live-p errbuf)
                     (kill-buffer errbuf))
                   (my/net-doctor--report
                    report-buffer label
                    (if (zerop code)
                        "ok"
                      (concat "FAILED - " (my/net-doctor--curl-exit code)))
                    (or (and (not (zerop code))
                             (not (string= errs ""))
                             errs)
                        out)))))))
        (error
         (my/net-doctor--report report-buffer label "FAILED"
                                (error-message-string err)))))

    (defun my/net-doctor--url-probe (report-buffer)
      "Deferred, asynchronous url.el probe used by `my/net-doctor'."
      (let* ((done (list nil))
             timer proc buf)
        (my/net-doctor--report report-buffer "url.el" "dialing..."
                               "synchronous DNS in Emacs may freeze it briefly; that freeze IS the finding (C-g cancels)")
        (condition-case err
            (progn
              (setq buf
                    (url-retrieve
                     "https://news.ycombinator.com"
                     (lambda (status &rest _)
                       (unless (car done)
                         (setcar done t)
                         (when (timerp timer)
                           (cancel-timer timer))
                         (let ((err (plist-get status :error)))
                           (my/net-doctor--report
                            report-buffer "url.el"
                            (if err "FAILED" "ok")
                            (if err
                                (format "%S - Emacs-side problem (NSM prompt/proxy/GnuTLS)" err)
                              "HTTP response received; Emacs networking works")))
                       (ignore-errors (kill-buffer (current-buffer)))))
                     nil t))
              (setq proc (and (bufferp buf) (get-buffer-process buf)))
              (setq timer
                    (run-at-time my/net-doctor-url-probe-timeout nil
                                 (lambda ()
                                   (unless (car done)
                                     (setcar done t)
                                     (when (and proc (process-live-p proc))
                                       (delete-process proc))
                                     (my/net-doctor--report
                                      report-buffer "url.el" "HANG - killed"
                                      (format "no response in %ss while curl reached the site: Emacs-side problem (NSM prompt, proxy vars, GnuTLS)"
                                              my/net-doctor-url-probe-timeout))))))
              (unless proc
                (unless (car done)
                  (setcar done t)
                  (when (timerp timer)
                    (cancel-timer timer))
                  (my/net-doctor--report report-buffer "url.el" "FAILED"
                                         "no process was started"))))
          (quit
           (unless (car done)
             (setcar done t)
             (when (timerp timer)
               (cancel-timer timer))
             (my/net-doctor--report report-buffer "url.el" "interrupted"
                                    "C-g stopped the dial - needing C-g here means Emacs DNS hangs (compare the curl lines)")))
          (error
           (unless (car done)
             (setcar done t)
             (when (timerp timer)
               (cancel-timer timer))
             (my/net-doctor--report report-buffer "url.el" "FAILED"
                                    (error-message-string err)))))))

    (defun my/net-doctor (&optional skip-url-probe)
      "Probe the network layers EWW and package.el depend on.
    Never blocks Emacs: every probe is either a `curl' subprocess with its
    own deadlines or an asynchronous `url-retrieve'.  No C-g required.

    With prefix arg SKIP-URL-PROBE, skip the url.el probe - the only probe
    that can briefly freeze Emacs while its DNS lookup runs (that freeze,
    with the curl probes ok, is itself the diagnosis).

    Interpreting the report:
      curl IPv4 FAILED        -> OS-level DNS or routing; fix outside Emacs.
      only curl IPv6 FAILED   -> black-holed IPv6; Emacs dials the AAAA
                                 address first and waits out the OS timeout.
                                 Fix at the OS/router level.
      curl all ok, url.el HANG or FAILED -> Emacs-side: stale proxy env vars
                                 (`url-proxy-services'), a hidden NSM
                                 certificate prompt, or GnuTLS (try the
                                 NORMAL:-VERS-TLS1.3 workaround noted above).
      DuckDuckGo http=202     -> DDG served its anti-bot challenge to this
                                 client (UA/IP reputation), NOT a network
                                 failure; see `my/eww-curl-user-agent'.
      everything ok           -> the site was slow or a one-off; retry
                                 (g in EWW, M-x package-refresh-contents)."
      (interactive "P")
      (require 'url-queue)
      (let ((buf (get-buffer-create "*net-doctor*")))
        (with-current-buffer buf
          (let ((inhibit-read-only t))
            (erase-buffer)
            (insert "Emacs network doctor (v3) - " (current-time-string) "\n"
                    (format "Emacs %s on %s, GnuTLS: %s\n"
                            emacs-version system-type
                            (if (and (fboundp 'gnutls-available-p)
                                     (gnutls-available-p))
                                "yes" "NO - https cannot work at all"))
                    (format "proxy env: %s | url-proxy-services: %s | network-security-level: %s\n\n"
                            (or (getenv "https_proxy") (getenv "HTTPS_PROXY")
                                (getenv "http_proxy") (getenv "HTTP_PROXY")
                                "none")
                            (if (boundp 'url-proxy-services)
                                (format "%S" url-proxy-services)
                              "not loaded yet")
                            (if (boundp 'network-security-level)
                                network-security-level
                              "?")))
            (special-mode)))
        (dolist (probe my/net-doctor-curl-probes)
          (my/net-doctor--run-curl buf (car probe) (cadr probe)))
        (if skip-url-probe
            (my/net-doctor--report buf "url.el" "skipped"
                                   "prefix arg given; rerun without it for the full picture")
          (my/net-doctor--report buf "url.el" "queued"
                                 "starts in 3s; may freeze Emacs briefly while dialing - that freeze is a finding")
          (run-at-time 3 nil #'my/net-doctor--url-probe buf))
        (pop-to-buffer buf)))

    ;; ---------------------------------------------------------------------------
    ;; my/net-nuke - the "unstick" command
    ;; ---------------------------------------------------------------------------

    (defun my/net-nuke ()
      "Delete stuck url.el network processes and clear the download queue.
    Run this right after C-g freed Emacs from a \"Contacting host ...\" or
    \"Loading ...\" freeze: killing the stalled connections lets their error
    callbacks fire, so EWW buffers stop showing \"Loading\" forever.
    Only url.el's own \" *http\" buffers and this config's leftover \"nd-\"
    probes are touched - LSP servers, IRC, etc. are left alone."
      (interactive)
      (require 'url-queue)
      (let (killed)
        (dolist (proc (process-list))
          (let ((buf (process-buffer proc)))
            (when (and (eq (process-type proc) 'network)
                       (or (string-match-p "\\`nd-" (process-name proc))
                           (and (buffer-live-p buf)
                                (string-match-p "\\` \\*http" (buffer-name buf)))))
              (push (process-name proc) killed)
              (ignore-errors (delete-process proc)))))
        ;; Drop queued fetch jobs; url-queue.el has no public cleaner.
        (setq url-queue nil)
        (when (timerp url-queue-progress-timer)
          (cancel-timer url-queue-progress-timer)
          (setq url-queue-progress-timer nil))
        (if killed
            (message "my/net-nuke: killed %d stuck network process(es): %s"
                     (length killed)
                     (mapconcat #'identity (nreverse killed) ", "))
          (message "my/net-nuke: no stuck network processes; queue cleared"))))
#+end_src

*** When Emacs is stuck — the runbook
1. =C-g= (press twice if needed).  Emacs is waiting inside an interruptible
   process filter, so this always comes back.
2. =M-x my/net-nuke= — kills the stalled " *http" connections so buffers stuck
   on "Loading ..." finish with an error instead of pretending to load forever.
3. =M-x my/net-doctor= — read the report matrix (also in its docstring):
   curl IPv4 FAILED -> OS-level DNS or routing; only curl IPv6 FAILED ->
   black-holed IPv6 (Emacs dials the AAAA address first); curl all ok but
   url.el HANG/FAILED -> Emacs-side trouble (stale proxy vars, a hidden NSM
   prompt, GnuTLS).
4. Fix what it names (DNS/IPv6 -> OS side; proxy vars -> =url-proxy-services=;
   TLS -> the =gnutls-algorithm-priority= line above; DuckDuckGo http=202 -> the
   [[*DuckDuckGo and Search][DuckDuckGo and Search]] section below; a
   certificate question sitting in the minibuffer -> NSM was waiting for you).
5. For any page-level failure the EWW error page carries the diagnosis itself:
   the exact URL handed to curl, curl's own message, the exit-code meaning and
   a code-specific hint.
6. Retry: =g= in the EWW buffer, or =M-x package-refresh-contents= (bounded by
   the advice above), then =M-x package-install=.

**** Resilient bootstrap
The stock =:ensure= machinery (=use-package-ensure-installed=) calls
=package-refresh-contents= synchronously during startup whenever a package is
missing from =package-archive-contents=.  On a slow or broken network that
freezes init on "Contacting host: melpa.org" with no timeout, and C-g leaves you
with half-installed packages.  The redefinition below (deliberately shadowing
the built-in of the same name, and tolerant of extra arguments) bounds every
bootstrap download, reports what it skipped, and lets startup continue; you
then fix the network (=M-x my/net-doctor=) and run =M-x package-refresh-contents=
plus =M-x package-install= by hand.

#+begin_src emacs-lisp
    (defvar my/package-bootstrap-timeout 45
      "Seconds a single package download may block startup before we give up.")

    (defvar my/package-refresh-done nil
      "Non-nil once package archives were refreshed during this startup.")

    (defvar my/package-network-down nil
      "Non-nil after the first bootstrap download failure in this session.
    Further missing packages are skipped so that startup still finishes.")

    (setq use-package-ensure-function #'my/ensure-installed)

    (defun my/ensure-installed (name _ensure _state &rest _)
      "Bounded, network-tolerant package bootstrap via the supported seam."
      (unless (package-installed-p name)
        (if my/package-network-down
            (message "[bootstrap] network down; skipping %s" name)
          (condition-case err
              (let ((result (with-timeout (my/package-bootstrap-timeout 'timed-out)
                              (unless (or my/package-refresh-done
                                          (assoc name package-archive-contents))
                                (package-refresh-contents)
                                (setq my/package-refresh-done t))
                              (package-install name)
                              'installed)))
                (unless (eq result 'installed)
                  (setq my/package-network-down t)
                  (message "[bootstrap] %s timed out; skipping" name)))
            ((error timeout)
             (setq my/package-network-down t)
             (message "[bootstrap] could not install %s (%s); skipping"
                      name (error-message-string err)))))))
#+end_src

** Eglot
Built in Emacs client for the Language Server Protocol.
We use Eglot because it is fast and minimal.
For more: C-h i: g: (eglot)Top

Eglot does not automatically download LSP servers. It requires a separate download.
The easiest way to install LSP servers is with a package manager like mason.el.

If you can't use a package manager you can do the following:
- Download the server (e.g. from github)
- Add the binary/executable to your path.
- Or customize the eglot-server-programs list.
To control how an LSP server is started customize the eglot-server-programs list.

There are many alternative LSP clients, one of them is LSP-mode.
Which has more features and supports automatic language server installation.
But it's bigger, so it has more moving parts.

We don't use it because Eglot is more than enough for most people.
If you want to use LSP mode check out their [[https://emacs-lsp.github.io/lsp-mode/][documentation]] or the [[https://github.com/MiniApollo/kickstart.emacs/wiki][project wiki]] page for more information.

** Cape
Provides Completion At Point Extensions which can be used in combination with Corfu, Company or the default completion UI.

We merge capfs together so they appear together in the completion list.
The ones not merged will display separately (Only their list will show up in the completion list).
Order matters. Since these functions run in sequence, the first one to return a list will prevent others from running.
Due to technical details, not all Capfs can be merged successfully (e.g cape-file).

Notes:
- Be aware when adding Capfs (Completion-at-point-functions) to the list since each of the Capfs adds a small runtime cost.
Read the [[https://github.com/minad/cape#configuration][configuration section]] in Cape's readme for more information.
#+begin_src emacs-lisp
    (use-package yasnippet-capf :defer t)

    (defun start/setup-capfs ()
      "Configure completion backends."
      ;; Take care when adding Capfs to the list since each of the Capfs adds a small runtime cost.
      (let ((merge-backends (list
                             ;; Snippy-capf needed to be first, so characters like !,@, etc. Works with Snippy.
                             ;; When cape-capf-super combines multiple completion functions, it uses the prefix boundaries of the first capf.
                             ;; Other capf have different prefix boundaries.
                             ;;#'snippy-capf       ; Vscode Snippets
                             #'yasnippet-capf    ; Yasnippet snippets
                             ;; #'cape-abbrev       ; Complete abbreviation
                             #'cape-dabbrev      ; Complete word from current buffers
                             #'cape-keyword      ; Keyword completion
                             ;; #'cape-line         ; Complete entire line from current buffer
                             ;; #'cape-history      ; Complete from Eshell, Comint or minibuffer history
                             ;; #'cape-dict         ; Dictionary completion (Needs Dictionary file installed)
                             ;; #'cape-tex          ; Complete Unicode char from TeX command, e.g. \hbar
                             ;; #'cape-sgml         ; Complete Unicode char from SGML entity, e.g., &alpha
                             ;; #'cape-rfc1345      ; Complete Unicode char using RFC 1345 mnemonics
                             ))
            (separate-backends (list
                                #'cape-file ; Path completion
                                #'cape-elisp-block ; Complete elisp in Org or Markdown mode
                                )))

        ;; Remove keyword and snippet completion in git commits
        (when (bound-and-true-p git-commit-mode)
          (dolist (backend '(cape-keyword snippy-capf yasnippet-capf))
            (setq merge-backends (remq backend merge-backends))))

        ;; Add Elisp symbols only in Elisp modes
        (when (derived-mode-p 'emacs-lisp-mode 'ielm-mode)
          (setq merge-backends (cons #'cape-elisp-symbol merge-backends))) ; Emacs Lisp code (functions, variables)

        ;; Add Eglot to the front of the list if it's active
        (when (bound-and-true-p eglot--managed-mode)
          (setq merge-backends (cons #'eglot-completion-at-point merge-backends)))

        ;; Create the super-capf and set it buffer-locally
        (setq-local completion-at-point-functions
                    (append
                     separate-backends
                     (list (apply #'cape-capf-super merge-backends))))))
    (use-package cape
      :after (corfu)
      :init
      ;; Add to the global default value of `completion-at-point-functions' which is
      ;; used by `completion-at-point'.  The order of the functions matters, the
      ;; first function returning a result wins.  Note that the list of buffer-local
      ;; completion functions takes precedence over the global list.

      ;; Separate function needed, because we use setq-local (everything is replaced)
      (add-hook 'eglot-managed-mode-hook #'start/setup-capfs)
      (add-hook 'prog-mode-hook #'start/setup-capfs)
      (add-hook 'text-mode-hook #'start/setup-capfs)
      (add-hook 'git-commit-setup-hook #'start/setup-capfs)) ; Fixes completion in magit commits
#+end_src

    ;; ---- curl-backed EWW fetching, v3 ---------------------------------
    ;; curl races IPv4/IPv6 (Happy Eyeballs), enforces its own
    ;; deadlines and runs as a subprocess, so a broken network can slow
    ;; pages but never freeze Emacs.  v3 adds: URL sanitizing (DDG's
    ;; challenge form ships a raw space in its action URL -> curl exit
    ;; 3), POST support (Emacs' eww-submit only feeds form data to
    ;; url.el; the external-command path used to DROP it), a persistent
    ;; cookie jar and -g/--globoff (curl was expanding [ ] { } in URLs
    ;; as glob ranges).

    (defcustom my/eww-curl-timeout 20
      "Seconds curl may spend fetching one EWW page (its own deadline)."
      :type 'integer)

    (defcustom my/eww-curl-use-cookies t
      "Let the curl fetcher keep a persistent cookie jar.
    Needed for logins and for flows like DuckDuckGo's anti-bot challenge,
    whose verification POST is tied to the session that received it.  The
    jar lives at `my/eww-curl-cookie-jar', next to url.el's own cookie
    file, with the same trust model."
      :type 'boolean)

    (defcustom my/eww-curl-cookie-jar
      (expand-file-name "url/curl-cookies.txt" user-emacs-directory)
      "Cookie jar file shared by all curl fetches (pages and downloads)."
      :type 'file)

    (defcustom my/eww-curl-user-agent nil
      "User-Agent string for curl page fetches, or nil for curl's own.
    curl's default UA (\"curl/8.x\") is one of the reasons anti-bot
    systems (DuckDuckGo, Cloudflare, ...) challenge text browsers.
    Setting a conventional browser string makes far fewer sites show
    captchas; nil keeps curl's honest default.  See Patch 3."
      :type '(choice (const :tag "curl default" nil) string))

    (defun my/url-safe-for-curl (url)
      "Percent-encode characters curl refuses outright in URL arguments.
    DuckDuckGo's anti-bot challenge page ships its form action with a raw,
    unencoded space inside the echoed query (...&q=two words&o=...), and
    curl exits with status 3 (\"URL rejected: Malformed input to a URL
    function\") on any URL containing a space, tab, CR or LF.  Browsers
    percent-encode those silently when submitting forms; so does this."
      (replace-regexp-in-string "[[:cntrl:] ]"
                                (lambda (ch)
                                  (format "%%%02X" (aref ch 0)))
                                url))

    (defun my/curl--ensure-cookie-jar ()
      "Create an empty cookie jar file if none exists yet.
    Avoids curl's \"failed to open cookie file\" warning on first use."
      (unless (file-exists-p my/eww-curl-cookie-jar)
        (make-directory (directory-file-name
                         (file-name-directory my/eww-curl-cookie-jar))
                        t)
        (with-temp-file my/eww-curl-cookie-jar)))

    (defun my/eww--html-escape (s)
      "Escape S for safe inclusion in HTML text and attribute values."
      (setq s (replace-regexp-in-string "&" "&amp;" s))
      (setq s (replace-regexp-in-string "<" "&lt;" s))
      (setq s (replace-regexp-in-string ">" "&gt;" s))
      (setq s (replace-regexp-in-string "\"" "&quot;" s))
      s)

    (defvar my/eww--curl-exit-hints
      '((3 . "The URL itself is malformed - usually a raw space or newline that the SITE's HTML shipped inside a link or form action (DuckDuckGo's anti-bot challenge form does exactly this with the echoed search query).  Browsers silently percent-encode such characters and this config now does too, so a repeat of exit 3 means something else in the page is broken: copy the URL shown above and inspect it.")
        (5 . "curl tried to reach a PROXY and failed: stale http_proxy/https_proxy environment variables?")
        (6 . "DNS could not resolve the host: resolver, VPN or /etc/hosts problem.  M-x my/net-doctor shows which layer.")
        (7 . "TCP connect refused or unreachable: server down, firewall or VPN blocking.")
        (22 . "The server answered with an HTTP 4xx/5xx status; whatever body it sent should be visible above or in the site's response.")
        (28 . "Timed out.  Run M-x my/net-doctor: curl IPv4 ok but curl IPv6 failed = black-holed IPv6 network; url.el HANG while curl is ok = Emacs-side trouble (proxy vars, NSM prompt, GnuTLS).")
        (35 . "TLS handshake failure.  If every curl probe in M-x my/net-doctor succeeds, compare Emacs' GnuTLS (see the NORMAL:-VERS-TLS1.3 note).")
        (47 . "Redirect loop - typically the site insists on session cookies; the cookie jar should cover this.  If one site still loops, try M-x my/eww-toggle-fetch-backend once.")
        (52 . "Server accepted the connection but sent an empty reply - often a bot-protection wall.")
        (60 . "TLS certificate could not be verified: check the system clock and CA store."))
      "Extra per-exit-code hints shown on the EWW curl error page.")

    (defun my/eww--curl-error-page (url exit-code stderr)
      "Build the diagnostic HTML page shown when curl exits with EXIT-CODE."
      (let ((meaning (my/net-doctor--curl-exit exit-code))
            (hint (cdr (assq exit-code my/eww--curl-exit-hints)))
            (safe-url (my/eww--html-escape url))
            (safe-err (my/eww--html-escape (string-trim (or stderr "")))))
        (concat
         "<!doctype html><html><head><title>Fetch failed: curl exit "
         (number-to-string exit-code)
         "</title></head><body>"
         "<h1>Fetch failed: curl exited with status "
         (number-to-string exit-code) "</h1>"
         "<p><b>URL (as handed to curl):</b> <a href=\"" safe-url "\">"
         safe-url "</a></p>"
         "<p><b>What this status means:</b> " meaning ".</p>"
         (when hint
           (concat "<p><b>Hint:</b> " hint "</p>"))
         (when (> (length safe-err) 0)
           (concat "<p><b>curl's own message:</b></p><pre>" safe-err "</pre>"))
         "<p><b>What now:</b> press <code>g</code> to retry this page, "
         "<code>&amp;</code> to open it in your graphical browser, or run "
         "<code>M-x my/net-doctor</code> to test every network layer.  If "
         "one site keeps failing while the doctor is green, the site's "
         "HTML or bot-protection is the problem - try "
         "<code>M-x my/eww-toggle-fetch-backend</code> once for comparison."
         "</p></body></html>")))

    (defun my/eww--build-curl-command ()
      "Build the curl argument list for `eww-retrieve-command'.
    -g/--globoff stops curl from treating [ ] { } in URLs as filename
    globbing ranges (a URL containing [0-9] would otherwise fetch a dozen
    wrong URLs instead of one); --compressed negotiates gzip;
    --connect-timeout 8 bounds the dial; -b/-c keep the persistent cookie
    jar so sessions and challenge flows survive between fetches."
      (append
       (list "curl" "-sS" "-g" "-L" "--compressed"
             "--connect-timeout" "8"
             "-m" (number-to-string my/eww-curl-timeout))
       (when my/eww-curl-use-cookies
         (list "-b" my/eww-curl-cookie-jar "-c" my/eww-curl-cookie-jar))
       (when my/eww-curl-user-agent
         (list "-A" my/eww-curl-user-agent))))

    (defun my/eww--write-post-data (data)
      "Write POST DATA to a temp file; curl reads it with --data-binary @FILE.
    A file (not the command line) is the right carrier: request bodies can
    be big and may contain bytes that cannot survive an argv array."
      (let ((file (make-temp-file "eww-post-"))
            (payload (if (multibyte-string-p data)
                         (encode-coding-string data 'utf-8)
                       data)))
        (with-temp-file file
          (set-buffer-multibyte nil)
          (insert payload))
        file))

    (defun my/eww--content-type (hdrs)
      "Content-Type of the final response from a curl -D dump."
      (let ((last (or (car (last (split-string hdrs "\r?\n\r?\n" t))) "")))
        (if (let ((case-fold-search t))
              (string-match "^content-type:[ \t]*\\([^\r\n]+\\)" last))
            (string-trim (match-string 1 last))
          "text/html; charset=utf-8")))

    (defun my/eww-retrieve-with-error-page (orig-fn url callback cbargs)
      "curl-backed `eww-retrieve' with real headers, redirect tracking, POST, cookies."
      (if (not (and (boundp 'eww-retrieve-command) (consp eww-retrieve-command)))
          (funcall orig-fn url callback cbargs)
        (let* ((method (and (boundp 'url-request-method) (symbol-value 'url-request-method)))
               (raw-data (and (boundp 'url-request-data) (symbol-value 'url-request-data)))
               (post-data (and raw-data (or (not method) (not (equal method "GET"))) raw-data))
               (extra-headers (and (boundp 'url-request-extra-headers)
                                   (symbol-value 'url-request-extra-headers)))
               (fetch-url (my/url-safe-for-curl url))
               (header-args nil)
               (datafile (when post-data (my/eww--write-post-data post-data)))
               (headfile (make-temp-file "eww-hdr-"))
               (bodyfile (make-temp-file "eww-body-"))
               (buf (generate-new-buffer " *eww retrieve*"))
               (errbuf (generate-new-buffer " *eww error*")))
          (when my/eww-curl-use-cookies (my/curl--ensure-cookie-jar))
          (with-current-buffer buf (set-buffer-multibyte nil))
          (dolist (h (or extra-headers '()))
            (when (and (consp h) (stringp (car h)) (stringp (cdr h)))
              (setq header-args (append header-args (list "-H" (concat (car h) ": " (cdr h)))))))
          (condition-case err
              (make-process
               :name "*eww fetch*" :buffer buf :stderr errbuf
               :command (append eww-retrieve-command header-args
                                (when datafile (list "--data-binary" (concat "@" datafile)))
                                (list "-D" headfile "-o" bodyfile "-w" "%{url_effective}")
                                (list fetch-url))
               :sentinel
               (lambda (process _event)
                 (unless (process-live-p process)
                   (let* ((exit (process-exit-status process))
                          (effective (and (buffer-live-p buf)
                                          (string-trim (with-current-buffer buf (buffer-string)))))
                          (stderr (and (buffer-live-p errbuf)
                                       (string-trim (with-current-buffer errbuf (buffer-string)))))
                          (final-url (if (string-empty-p effective) fetch-url effective)))
                     (when (buffer-live-p errbuf) (kill-buffer errbuf))
                     (when datafile (ignore-errors (delete-file datafile)))
                     (when (buffer-live-p buf)
                       (with-current-buffer buf
                         (erase-buffer)
                         (if (not (zerop exit))
                             (progn
                               (message "my/eww: curl exit %s fetching %s%s" exit fetch-url
                                        (if (string= stderr "") "" (concat " - " stderr)))
                               (insert (encode-coding-string
                                        (my/eww--curl-error-page fetch-url exit stderr) 'utf-8))
                               (goto-char (point-min))
                               (insert "Content-type: text/html; charset=utf-8\n\n")
                               (apply callback nil cbargs))
                           (let ((ct (my/eww--content-type
                                      (with-temp-buffer (insert-file-contents headfile) (buffer-string))))
                                 (body (with-temp-buffer (set-buffer-multibyte nil)
    						     (insert-file-contents bodyfile) (buffer-string))))
                             (insert "Content-type: " ct "\n\n")
                             (insert body))
                           (goto-char (point-min))
                           ;; make relative links/history use the post-redirect URL
                           (apply callback nil (cons final-url (cdr cbargs))))))
                     (ignore-errors (delete-file headfile))
                     (ignore-errors (delete-file bodyfile))))))
            (error
             (when datafile (ignore-errors (delete-file datafile)))
             (ignore-errors (delete-file headfile))
             (ignore-errors (delete-file bodyfile))
             (ignore-errors (kill-buffer buf))
             (ignore-errors (kill-buffer errbuf))
             (signal (car err) (cdr err)))))))

    (with-eval-after-load 'eww
      (setq eww-retrieve-command (my/eww--build-curl-command))
      (advice-add 'eww-retrieve :around #'my/eww-retrieve-with-error-page))

    (defvar my/eww--curl-fetch-command nil
      "curl argument list captured while the curl backend is active.")

    (defun my/eww-toggle-fetch-backend ()
      "Flip EWW between the curl subprocess fetcher and Emacs' built-in url.el.
    url.el understands NSM certificate prompts and proxies, but it has NO
    fetch timeout - the original \"Loading ...\" freezes are possible again
    while it is active.  Treat this as a one-off escape hatch for a site
    that misbehaves under curl, not as a mode."
      (interactive)
      (unless (boundp 'eww-retrieve-command)
        (require 'eww))
      (if (consp eww-retrieve-command)
          (progn
            (setq my/eww--curl-fetch-command eww-retrieve-command
                  eww-retrieve-command nil)
            (message "EWW fetch backend: url.el (built-in, NO fetch timeout - the old freezes are possible again)."))
        (setq eww-retrieve-command
              (or my/eww--curl-fetch-command (my/eww--build-curl-command)))
        (message "EWW fetch backend: curl subprocess (bounded, cookie jar on).")))

    ;; Bounded downloads: unlike `url-copy-file' (synchronous, no
    ;; timeout — hangs for minutes on a broken network), curl enforces
    ;; its own DNS/connect/transfer deadlines.  Shares the cookie jar
    ;; with page fetches, so authenticated downloads keep working.
    ;; Now it takes a _callback_
    (defun my/curl-download (url dest callback &optional timeout)
      "Download URL to DEST asynchronously; call CALLBACK with DEST on success."
      (if (not (executable-find "curl"))
          (progn (url-copy-file url dest t) (funcall callback dest))
        (when my/eww-curl-use-cookies (my/curl--ensure-cookie-jar))
        (let ((errbuf (generate-new-buffer " *curl-download stderr*")))
          (make-process
           :name "curl-download" :buffer nil :stderr errbuf
           :command (append (list "curl" "-sS" "-g" "-L" "-f"
                                  "-m" (number-to-string (or timeout 30)))
                            (when my/eww-curl-use-cookies
                              (list "-b" my/eww-curl-cookie-jar "-c" my/eww-curl-cookie-jar))
                            (when my/eww-curl-user-agent (list "-A" my/eww-curl-user-agent))
                            (list "-o" dest "--" (my/url-safe-for-curl url)))
           :sentinel
           (lambda (proc _event)
             (unless (process-live-p proc)
               (let ((exit (process-exit-status proc))
                     (errs (and (buffer-live-p errbuf)
                                (string-trim (with-current-buffer errbuf (buffer-string))))))
                 (when (buffer-live-p errbuf) (kill-buffer errbuf))
                 (if (zerop exit)
                     (funcall callback dest)
                   (ignore-errors (delete-file dest))
                   (message "Download failed (curl: %s): %s%s"
                            (my/net-doctor--curl-exit exit) url
                            (if (string= errs "") "" (concat " - " errs)))))))))))

    (defun my/eww-download-image-at-point ()
      "Download the image at point to `eww-download-directory'.
    Uses `my/curl-download' (20 s deadline) instead of `url-copy-file'."
      (interactive)
      (let ((url (or (get-text-property (point) 'image-url)
                     (get-text-property (point) 'shr-url))))
        (if (not url)
            (message "No image at point")
          (require 'url-parse)
          (let* ((raw (file-name-nondirectory
                       (url-filename (url-generic-parse-url url))))
                 (name (replace-regexp-in-string "[/?&=]+" "_" raw))
                 (name (if (or (string= name "") (string= name "_"))
                           (format-time-string "image-%Y%m%d-%H%M%S")
                         name))
                 (dest (expand-file-name name eww-download-directory)))
            (make-directory eww-download-directory t)
            (my/curl-download url dest (lambda (f) (message "Saved: %s" f)) 20)
            (message "Saved: %s" dest)))))
#+end_src

** DuckDuckGo and Search
EWW already searches via the non-JS DuckDuckGo endpoint (=eww-search-prefix=
in the previous section is set to exactly that), so no prefix change is
needed for DDG.  When DuckDuckGo serves its anti-bot challenge
("Unfortunately, bots use DuckDuckGo too..."), the cause is not networking —
it is how the client presents itself (User-Agent, IP reputation, absent
cookies).  Two levers:

#+begin_src emacs-lisp
    ;; Lever 1: stop advertising "curl/8.x".  Anti-bot systems weigh the
    ;; User-Agent heavily; curl's default is a guaranteed challenge on
    ;; many sites.  A conventional browser string makes DDG challenges
    ;; rare.  (You decide the honesty trade-off.)
    (setq my/eww-curl-user-agent
          "Mozilla/5.0 (X11; Linux x86_64; rv:132.0) Gecko/20100101 Firefox/132.0")

    ;; Lever 2 (only if DDG still challenges or loops): point EWW's
    ;; search prefix at an endpoint/engine that tolerates text clients.
    ;; Pick ONE; keep the others commented for quick testing.
    ;; (setq eww-search-prefix "https://lite.duckduckgo.com/lite/?q=")
    ;; (setq eww-search-prefix "https://www.mojeek.com/search?q=")   ; no-challenge policy
    ;; (setq eww-search-prefix "https://search.marginalia.nu/search?query=")
    ;; (setq eww-search-prefix "https://www.bing.com/search?q=")

Two honest caveats: even with cookies and a browser User-Agent, DuckDuckGo
may still fingerprint the client and refuse the challenge answer — its puzzle
POST is now well-formed (the curl fetcher ships it, tied to the cookie jar),
but a site that insists on a real browser cannot be satisfied from EWW.  And
the second lever exists because a VPN/datacenter IP changes the odds as much
as any client setting does.

** URL Routing & External Programs
Videos go to mpv, PDFs open inside Emacs, gopher/gemini go to elpher,
local HyperSpec pages go to the dedicated =*clhs*= buffer (Lisp Languages
section), and everything else opens in EWW.  This table only routes links
opened through Emacs (=org-open-at-point=, package buttons, =M-x
browse-url=); =M-x eww= is always EWW.  There is no =.= catch-all in the
table any more: EWW is instead the =browse-url-browser-function= fallback,
which is what un-breaks =&= (open the current page in Firefox).

#+begin_src emacs-lisp
    (defun my/browse-url-mpv (url &rest _args)
      "Open URL in mpv (video sites); fall back to EWW when mpv is missing."
      (if (executable-find "mpv")
          (start-process "mpv" nil "mpv" url)
        (message "mpv not found, opening in EWW instead")
        (eww-browse-url url)))

    (defun my/browse-url-pdf (url &rest _args)
      (let ((tmp (make-temp-file "emacs-pdf-" nil ".pdf")))
        (my/curl-download url tmp
    		      (lambda (f) (find-file-other-window f)
    			(when (fboundp 'pdf-view-mode) (pdf-view-mode)))
    		      60)))

    ;; Gopher and gemini, the smolweb.  Loaded eagerly on purpose so
    ;; `elpher-browse-url-elpher' is defined when a gemini:// link is
    ;; clicked.
    (use-package elpher
      :ensure t)

    ;; Render PDFs with pdf-tools instead of doc-view.  Delete this block
    ;; if you prefer doc-view; the handler above copes either way.
    (use-package pdf-tools
      :mode ("\\.pdf\\'" . pdf-view-mode)
      :config (pdf-loader-install))

    ;; First matching regexp wins.  Do NOT put a "." catch-all in this
    ;; table: `browse-url' consults `browse-url-handlers' BEFORE falling
    ;; back to `browse-url-browser-function', so a catch-all hijacks every
    ;; path that tries to leave EWW through `browse-url' — including `&'
    ;; in EWW, which binds `browse-url-browser-function' to the secondary
    ;; browser and calls `browse-url'.  The old catch-all sent every such
    ;; request straight back to EWW: that was the "& does not open
    ;; Firefox" bug.
    (setq browse-url-handlers
          `(("\\(youtube\\.com\\|youtu\\.be\\|vimeo\\.com\\|twitch\\.tv\\)" . my/browse-url-mpv)
            ("\\.mp4$" . my/browse-url-mpv)
            ("\\.pdf$" . my/browse-url-pdf)
            ("^gemini://" . elpher-browse-url-elpher)
            ("^gopher://" . elpher-browse-url-elpher)
            (,(concat "^file://" (regexp-quote (expand-file-name "quicklisp/" "~")))
             . my/eww-browse-clhs)))

    ;; EWW is the default browser: this is the fallback `browse-url' uses
    ;; when NO handler above matched.  Same net effect as the old
    ;; catch-all, but on the right knob.
    (setq browse-url-browser-function #'eww-browse-url)

    ;; Where "&" in EWW sends pages that EWW cannot render.
    (setq browse-url-secondary-browser-function 'browse-url-generic
          browse-url-generic-program "firefox") ; adjust to firefox, google-chrome, ...

    ;; `&' must ALWAYS leave Emacs — even for URLs the routing table
    ;; claims (youtube -> mpv, .pdf -> inside Emacs).  The stock
    ;; `eww-browse-with-external-browser' goes back through `browse-url',
    ;; where the routing table would re-route those.  This bypass is
    ;; deterministic: secondary browser, no dispatch.
    (defun my/eww-open-in-secondary-browser (&optional url)
      "Open URL (default: the current EWW page) in the secondary browser.
    Bypasses `browse-url-handlers' on purpose: the routing table decides
    what happens INSIDE Emacs; `&' always leaves."
      (interactive nil eww-mode)
      (let ((url (or url (plist-get eww-data :url))))
        (if (functionp browse-url-secondary-browser-function)
            (funcall browse-url-secondary-browser-function url)
          ;; Alist form (REGEXP . FN): delegate to `browse-url' with the
          ;; routing table disarmed so the secondary choice wins.
          (let ((browse-url-handlers nil)
                (browse-url-browser-function
                 browse-url-secondary-browser-function))
            (browse-url url)))))

    (with-eval-after-load 'eww
      (define-key eww-mode-map (kbd "&")
                  #'my/eww-open-in-secondary-browser))
#+end_src

renamed to the =my/= convention, reshaped to this configuration's

unbounded url.el).  Replace every PERSONAL value (nick, channels, feeds)
with your own.  Two of studium's ERC options were dropped because they no

(removed; ERC's =log= module is the modern way to keep logs) and
=erc-auto-query= (obsolete alias; today's default
=erc-receive-query-display= of =window-noselect= already shows DMs

** ERC (IRC)
ERC is built into Emacs 29+, so there is nothing to install.  The
=move-to-prompt= module pins the input prompt at the bottom, =track=
reports unread activity per buffer (modeline), =match= plus
=my/erc-notify-on-mention= produce desktop notifications on mentions, and
the =fill= module's =erc-fill-wrap= function gives ERC the modern wrapped
look.  Connect with =C-c i c= or =M-x my/erc-connect=: the NickServ
password comes from =auth-sources= (put a line like
=machine irc.libera.chat login YOURNICK password SECRET= into
=~/.authinfo.gpg=; Libera treats the server password as a NickServ
identify).  With evil, ERC buffers start in normal state — press =i= at
the prompt to talk.
#+begin_src emacs-lisp
    (use-package erc
      :ensure nil                    ; built into Emacs 29+
      :commands (erc erc-tls)
      :init
      (setq erc-modules '(autojoin button completion fill irccontrols list
                                  match menu move-to-prompt netsplit
                                  networks noncommands readonly ring stamp
                                  track)
            erc-server "irc.libera.chat"     ; PERSONAL: your network
            erc-port 6697
            erc-autojoin-channels-alist      ; PERSONAL: your channels
            '(("Libera.Chat" "#emacs" "#org-mode"))
            erc-track-shorten-start 8
            erc-kill-buffer-on-part t
            erc-fill-column 100
            erc-fill-function 'erc-fill-wrap
            erc-fill-wrap-merge t
            erc-interpret-mirc-color t
            ;; Wait 10s between reconnect attempts (default 1s) so a dead
            ;; VPN or link cannot produce a background reconnect storm.
            erc-server-reconnect-timeout 10)
      :config
      (add-hook 'erc-text-matched-hook #'my/erc-notify-on-mention))

    (defun my/erc-connect ()
      "Connect to IRC over TLS; NickServ password from `auth-sources'."
      (interactive)
      (let ((password (auth-source-pick-first-password
                       :host erc-server :user erc-nick)))
        (if password
            (erc-tls :server erc-server :port erc-port
                     :nick erc-nick :password password)
          (message "ERC: no auth-source password for %s@%s; connecting without"
                   erc-nick erc-server)
          (erc-tls :server erc-server :port erc-port :nick erc-nick))))

    (defun my/erc-notify-on-mention (match-type nickuserhost message)
      "Desktop notification when someone mentions our nick.
MATCH-TYPE, NICKUSERHOST and MESSAGE follow `erc-text-matched-hook'
(the NUH looks like \"bob!~bob@example.org\")."
      (when (and (eq match-type 'current-nick)
                 (not (string-match-p "^\\** *Users on " message))
                 (executable-find "notify-send"))
        (start-process "erc-notify" nil "notify-send"
                       "-i" "emacs" "-u" "normal"
                       (format "ERC: %s" (buffer-name))
                       (format "%s: %s"
                               (erc-extract-nick nickuserhost) message))))

browse-url routing table.  Feeds are the plain =elfeed-feeds= list below
— swap in your own.  (studium instead syncs against a self-hosted

    (defun my/elfeed--tagify (name)
      "Convert an OPML folder NAME into an Elfeed tag symbol."
      (let* ((s (downcase name))
             (s (replace-regexp-in-string "[^a-z0-9]+" "-" s))
             (s (replace-regexp-in-string "\\`-+\\|-+$" "" s)))
        (if (equal s "") nil (intern s))))

    (defun my/elfeed--opml-tagged (xml tags)
      "Like `elfeed--parse-opml', but OPML folder names become tags.
    XML is a tree from `elfeed-xml-parse-file'; TAGS is accumulated."
      (cl-loop for (_tag attr . content) in (cl-remove-if-not #'listp xml)
               if (assoc 'xmlUrl attr)
               collect (if tags (cons (cdr it) tags) (cdr it))
               else append
               (let* ((name (or (cdr (assoc 'text attr))
                                (cdr (assoc 'title attr))))
                      (tag (and name (my/elfeed--tagify name))))
                 (my/elfeed--opml-tagged
                  content (if tag (cons tag tags) tags)))))

    (defun my/elfeed-import-opml (file)
      "Import feeds from an OPML FILE into `elfeed-feeds'.
    Folder names become tags; existing feeds are kept, duplicate URLs
    dropped.  Shows a paste-ready (setq elfeed-feeds ...) form for init.org."
      (interactive "fOPML file: ")
      (require 'elfeed)
      (require 'cl-lib)
      (let* ((xml (elfeed-xml-parse-file file))
             (imported (my/elfeed--opml-tagged xml nil))
             (seen (make-hash-table :test #'equal))
             (entries (cl-loop for entry in (append imported elfeed-feeds)
                               for url = (if (consp entry) (car entry) entry)
                               for tags = (and (consp entry) (cdr entry))
                               unless (gethash url seen)
                               collect (progn (puthash url t seen)
                                              (if tags (cons url tags) url)))))
        (setf elfeed-feeds entries)
        (with-current-buffer (get-buffer-create "*elfeed-feeds-import*")
          (erase-buffer)
          (insert (format ";; %d entries imported from %s, %d unique feeds.\n"
                          (length imported) (abbreviate-file-name file)
                          (length entries))
                  ";; Paste this form over the elfeed-feeds value in init.org:\n\n"
                  (pp-to-string `(setq elfeed-feeds ',entries)))
          (emacs-lisp-mode)
          (goto-char (point-min)))
        (pop-to-buffer "*elfeed-feeds-import*")
        (message "Elfeed: %d entries imported, %d unique feeds total"
                 (length imported) (length entries))))

    ;; Entry points in the C-c leader map (see General Keybindings).
    (start/leader-keys
      "i" '(:ignore t :wk "IRC & RSS")
      "i c" '(my/erc-connect :wk "ERC: connect")
      "i f" '(elfeed :wk "Elfeed: RSS reader")
      "i u" '(elfeed-update :wk "Elfeed: update feeds"))
